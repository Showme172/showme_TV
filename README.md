# Showme TV — الموقع (React + Supabase)

## الحالة الحالية — شو شغال وشو بيحتاج خطوة منك

✅ **شغال فوراً بمجرد ما تربط Supabase (خطوات 1-4):**
- كل صفحات الموقع + الأنيميشن.
- فورم الدعم واللايف تشات → بتوصل مباشرة لصندوق الأدمن.
- لوحة `/admin`: تسجيل دخول، صندوق رسائل، تعديل الأسعار/المزايا بشكل حي، صفحة "آراء الزبائن" و"التطبيقات" تدار بالكامل من اللوحة.
- **لايف تشات حقيقي ثنائي الاتجاه:** لو موظف أونلاين، الزبون بيشوف رقمه (#1080 مثلاً) وبتصير محادثة حية فعلية، مو مجرد فورم.
- **نظام موظفين:** رقم عشوائي 1000-1999 تلقائي لكل موظف، فقط المالك بيشوف صفحة "الموظفون"، وفيك تحط/تعدّل اسم كل موظف كملاحظة خاصة.

⚠️ **بيحتاج خطوة نشر إضافية (Edge Function) — موضح تحت:**
- إنشاء حسابات موظفين جدد من اللوحة (تبويب "الموظفون").
- استقبال رسائل تيليجرام الحقيقية (يلي الزبون يبعتها من تطبيق تيليجرام نفسه) داخل صندوق الأدمن، والرد عليها من نفس اللوحة.

❌ **مو مبني، وما بنصح فيه:**
- دمج واتساب ويب أو ماسنجر بشكل مباشر جوا اللوحة — ممنوع/خطير تقنياً (شرح كامل بالمحادثة). البديل: أي رسالة توصلك عليهم بتضل بتطبيقهم العادي.
- ذكاء اصطناعي يرد على أسئلة مفتوحة — بيحتاج مفتاح API لخدمة ذكاء اصطناعي، قلي إذا بدك نضيفه.

✅ **نتائج المباريات المباشرة:** مبنية بالكامل، بس بتحتاج مفتاح API مجاني منك (خطوات تحت). بتظهر تلقائياً بس وقت في مباراة شغالة، وبتختفي أوتوماتيك لما ما يكون في.

## الإعداد الأساسي (لازم تسويه أول شي)

### 1) شغّل ملفي قاعدة البيانات بالترتيب

من مشروعك بـ supabase.com → **SQL Editor**:
1. الصق محتوى `supabase/schema.sql` كامل → اضغط **Run**.
2. بعدها الصق محتوى `supabase/schema_v2.sql` كامل → اضغط **Run**.

(schema_v2 بيضيف: أرقام الموظفين، اللايف تشات ثنائي الاتجاه، حضور الموظفين أونلاين/أوفلاين، آراء الزبائن، التطبيقات، و Storage buckets لحفظ الصور).

### 2) خلّي حسابك "مالك"

بآخر سطور `schema_v2.sql` فيه أمر معلّق (مبدوء بـ `--`). شيل التعليق وبدّل الإيميل بإيميلك، وشغّله لحاله بـ SQL Editor:
```sql
update public.profiles set role = 'owner', display_name = 'المالك'
where id = (select id from auth.users where email = 'showmetv@gmail.com');
```

### 3) مفاتيح المشروع

من **Settings → API**: انسخ **Project URL** و **anon / publishable key**، وحطهم بملف `.env` (انسخ `.env.example` وسمّيه `.env`):
```
VITE_SUPABASE_URL=https://xxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ... أو sb_publishable_...
```

### 4) شغّل وجرّب

```
npm install
npm run dev
```
افتح `/admin`، سجّل دخول بحسابك، وجرّب كل تبويب.

### 5) النشر (Netlify — الأسهل)

```
npm run build
```
بعدها اسحب مجلد `dist/` وفلته على **app.netlify.com/drop**.

## خطوة إضافية 1: تفعيل إضافة الموظفين من اللوحة

بإنشاء حساب موظف عملية حساسة أمنياً، فمو بتصير من المتصفح مباشرة — بتحتاج نشر ملف صغير (Edge Function):

```
npm install -g supabase
supabase login
supabase link --project-ref your-project-ref
supabase functions deploy create-agent
```
بعدها تبويب "الموظفون" (يظهر إلك بس، كمالك) بيصير شغال بالكامل.

## خطوة إضافية 2: ربط تيليجرام كقناة واردة بصندوق الأدمن

هيك أي رسالة توصل حسابك على تيليجرام (@Showme_TV) بتظهر وتترد عليها من نفس صندوق الأدمن:

1. افتح تيليجرام وابحث عن **@BotFather**، ابعتله `/newbot` واتبع التعليمات (اسم + username للبوت). رح يعطيك **توكن** (نص طويل).
2. من جهازك (بعد `supabase login` و `supabase link` من فوق):
   ```
   supabase secrets set TELEGRAM_BOT_TOKEN=التوكن_يلي_عطاك_ياه_BotFather
   supabase functions deploy telegram-webhook --no-verify-jwt
   supabase functions deploy telegram-reply
   ```
3. فعّل الرابط عند تيليجرام (بدّل TOKEN و PROJECT_REF بالقيم الحقيقية، والصق بالمتصفح):
   ```
   https://api.telegram.org/botTOKEN/setWebhook?url=https://PROJECT_REF.supabase.co/functions/v1/telegram-webhook
   ```

**مهم:** هاد بوت جديد، مو حسابك الشخصي @Showme_TV. لازم تربطه بقناتك أو تحوّل الزبائن يحكوا معه بدل حسابك الشخصي، أو تربطه كـ "مدير" على نفس اليوزر — التفاصيل بتفرق حسب شكل حسابك الحالي، قلي شو عندك بالضبط ونظبطها مع بعض.

## خطوة إضافية 3: نتائج المباريات المباشرة (مجاني، وبس وقت في مباراة)

**كيف بتشتغل:** كل 5 دقايق، فحص خفيف بيصير. إذا ما في مباراة شغالة وآخر فحص كان قبل أقل من 25 دقيقة، ما بيصير أي طلب فعلي عالـ API (صفر تكلفة). إذا في مباراة شغالة، أو مرّ وقت كافي، بيصير طلب واحد بس (بغض النظر عن عدد المباريات). بيوم عادي بدون مباريات: ~48 طلب. بيوم فيه مباريات كتير: ممكن يزيد شوي، بس بيضل قريب من حد الـ 100 المجاني.

### 1) سجّل حساب مجاني واحصل على مفتاح

روح لـ **api-football.com** (أو نفس الخدمة عبر rapidapi.com — API-Sports)، سجّل حساب مجاني، وخد **API Key** من لوحة حسابك. الخطة المجانية: 100 طلب/يوم.

### 2) شغّل ملف قاعدة البيانات الثالث

من SQL Editor، الصق محتوى `supabase/schema_v3.sql` كامل واضغط **Run**.

### 3) فعّل الجدولة التلقائية (Cron)

1. من لوحة Supabase: **Database → Extensions** → فعّل `pg_cron` و `pg_net`.
2. ثبّت التوكن ومفتاح الرياضة كأسرار (من جهازك، بعد `supabase login` و `supabase link`):
   ```
   supabase secrets set SPORTS_API_KEY=مفتاحك_من_api-football
   supabase secrets set CRON_SECRET=أي-نص-عشوائي-تختاره-إنت
   ```
3. انشر الدالة:
   ```
   supabase functions deploy update-scores --no-verify-jwt
   ```
4. من SQL Editor، شغّل الأمر `cron.schedule(...)` الموجود بآخر ملف `schema_v3.sql` — بس شيل التعليق وبدّل `PROJECT_REF` و `CRON_SECRET` بالقيم الحقيقية تبعتك (نفس CRON_SECRET يلي حطيته بالخطوة اللي فوق).

بعد هيك، بانر النتائج المباشرة بيظهر تلقائياً بالصفحة الرئيسية بس وقت في مباراة، وبيختفي وحده لما تخلص.

**ملاحظة:** الدالة حالياً بتعرض كل المباريات المباشرة بالعالم. إذا بدك تحصرها بدوريات معينة (الدوري الإنجليزي، الإسباني...)، فيك تضيف أرقام الدوريات (League ID) بمصفوفة `LEAGUE_WHITELIST` بأول ملف `supabase/functions/update-scores/index.ts` — الأرقام موجودة بتوثيق API-Football.

## خطوة إضافية 4: الإعلانات المؤقتة (نافذة منبثقة تلقائية)

من SQL Editor، الصق محتوى `supabase/schema_v4.sql` كامل واضغط **Run**. بعدها تبويب "الإعلانات" بلوحة التحكم بيصير شغال — تكتب رسالة وتحدد مدتها بالساعات، وبتظهر تلقائياً كنافذة منبثقة لأي زائر جديد يفتح الموقع، وبتختفي وحدها بعد ما تخلص المدة.

```
src/
  config.js                    ← القيم الافتراضية (قبل ربط Supabase)
  context/ConfigContext.jsx    ← الإعدادات الحية من Supabase
  hooks/
    useSendMessage.js          ← إرسال فورم الدعم
    useApps.js / useReviews.js ← جلب التطبيقات وآراء الزبائن
  components/
    Header, Footer, Ticker, LiveChat, FeatureGrid, PricingGrid...
  pages/
    Home, Features, Channels, Pricing, Support, Reviews, Downloads
    admin/
      Admin.jsx           ← الحاوية الرئيسية + تسجيل الدخول + الحضور
      AdminInbox.jsx       ← رسائل الموقع + رد تيليجرام
      AdminConversations.jsx ← اللايف تشات (رد حي)
      AdminSettings.jsx    ← تعديل الأسعار/المزايا حياً
      AdminReviews.jsx     ← رفع آراء الزبائن
      AdminApps.jsx        ← إدارة التطبيقات
      AdminAgents.jsx      ← إدارة الموظفين (owner فقط)
supabase/
  schema.sql        ← الجداول الأساسية (رسائل، إعدادات، موظفين)
  schema_v2.sql      ← الإضافات (لايف تشات، حضور، آراء، تطبيقات، storage)
  schema_v3.sql      ← نتائج المباريات المباشرة
  schema_v4.sql      ← الإعلانات المؤقتة
  functions/
    create-agent/        ← إنشاء حساب موظف
    telegram-webhook/    ← استقبال رسائل تيليجرام
    telegram-reply/      ← الرد على تيليجرام من اللوحة
    update-scores/       ← فحص وتخزين نتائج المباريات المباشرة
```
